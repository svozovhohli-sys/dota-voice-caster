# dota-voice-caster

Голосовое управление **Invoker** в Dota 2. Говорите «**Джарвис** + заклинание» —
приложение само нажимает орбы, `R` (Invoke) и кнопку каста (`D`).

Работает **оффлайн** (Vosk), поддерживает **Windows** и **Linux**.

```
«Джарвис, заморозься»        ->  Q Q Q R D   (Cold Snap)
«Джарвис, призрачная походка» ->  Q Q W R D   (Ghost Walk)
«Джарвис, взлетите»           ->  W W Q R D   (Tornado)
«Джарвис, великий тефтель»    ->  E E W R D   (Chaos Meteor)
```

## Быстрый старт

### Linux (ты)

```bash
cd dota-voice-caster
./run.sh --download-model ru    # скачать модель речи (~44 МБ), один раз
./run.sh --list-devices         # посмотреть микрофоны (по желанию)
./run.sh --calibrate            # проверить, что ВАШ голос распознаётся
./run.sh                        # боевой режим
```

Нужен эмулятор клавиш:

```bash
# X11:
sudo apt install xdotool
# Wayland:
sudo apt install ydotool && ydotoold &
```

### Windows — подробная инструкция (для друга)

Дополнительных утилит не нужно: используется системный `SendInput` со
scancode-кодами, которые понимают игры (Dota 2 в их числе).

**Шаг 1. Установить Python**

1. Открыть https://www.python.org/downloads/windows/ и скачать
   «Windows installer (64-bit)», версия **3.10–3.12** (3.12 проверена).
2. В установщике **обязательно** поставить галочку **«Add python.exe to PATH»**
   (внизу окна), затем «Install Now».
3. Проверить: `Win+R` → написать `cmd` → Enter, в консоли:
   ```bat
   py --version
   ```
   Должно вывести версию Python. Если пишет «не найден» — Python не попал в
   PATH, переустановите с галочкой.

**Шаг 2. Распаковать архив**

1. Получить `dota-voice-caster.zip` (см. «Передать другу» ниже).
2. Распаковать **целиком** в удобную папку без пробелов и кириллицы в пути,
   например `C:\dota-voice-caster`. Не запускать изнутри архива/из временной
   папки.

**Шаг 3. Первый запуск**

1. Двойной клик по `run.bat` — он сам создаст окружение, установит
   зависимости и запустит приложение.
2. Скачать модель речи (нужен интернет, один раз):
   ```bat
   run.bat --download-model ru
   ```
   Это ~44 МБ (быстрая модель для любого железа). **Для мощного ПК** лучше
   полная модель (~1.9 ГБ), см. раздел «Качественная модель».

**Шаг 4. Настроить микрофон**

1. «Панель управления → Звук → Запись»: выбрать нужный микрофон, поднять
   уровень, проверить индикатор.
2. Проверить, что приложение его видит и слышит:
   ```bat
   run.bat --list-devices      rem список микрофонов (если несколько)
   run.bat --device 1          rem выбрать нужный (номер из списка)
   run.bat --calibrate         rem сказать каждую фразу, посмотреть распознавание
   ```

**Шаг 5. Проверить эмуляцию клавиш**

```bat
run.bat --test-keys
```
Через 3 секунды приложение нажмёт `q w e r d`. Переключитесь на это время в
Блокнот — должны появиться буквы. Если нет — см. «Если что-то не работает».

**Шаг 6. Запуск в Dota 2**

1. Запустить `run.bat` (боевой режим) и дождаться строки «Слушаю микрофон».
2. Запустить Dota 2 в режиме **«Оконный»** или **«Рамка без границ»
   (Borderless Windowed)** — так эмулятор стабильно попадает в игру.
3. Сказать «**Джарвис**, <заклинание>».
4. Клавиши уходят в **активное окно**: если фокус на Dota — кастует; если
   переключились в браузер — нажимается там.

**Частые вопросы**

* **Клавиши не нажимаются в игре.** Запустите `run.bat` **от имени
  администратора** (ПКМ → «Запуск от имени администратора»), если сама Dota
  запущена от админа. Также помогает режим «Рамка без границ».
* **Windows Defender / антивирус ругается.** Приложение эмулирует ввод —
  это ожидаемо. Добавьте папку в исключения.
* **`py` не найден.** Python установлен без галочки «Add to PATH» —
  переустановите.
* **Микрофон не найден.** `run.bat --list-devices`, затем `run.bat --device N`.
* **Слова плохо распознаются.** `run.bat --calibrate`, подберите поле `words`
  в `commands.json` (см. раздел про слова-ключи).
* **Модель не докачалась.** Просто запустите `--download-model` снова —
  докачает с места обрыва.
* **SSK/Polina (режим-челлендж) не ловится.** Запустите `run.bat` **от админа**:
  глобальный перехват клавиш требует тех же прав, что и Dota. Игра — в режиме
  «Рамка без границ», оверлей виден поверх. См. раздел «SSK mode / Polina mode».

**Автозапуск (по желанию)**

Создайте ярлык на `run.bat` и положите в папку автозагрузки: `Win+R` →
`shell:startup` → Enter.

## Качественная модель для мощного ПК

По умолчанию используется `vosk-model-small-ru-0.22` (~45 МБ) — она
работает даже на слабом железе. Если компьютер мощный (друг — да), ставьте
полную модель `vosk-model-ru-0.42` (~1.9 ГБ): она заметно точнее и знает
больше слов.

```bat
run.bat --download-model ru-big          rem ~1.9 ГБ, скачается с дожатием при обрывах
run.bat --set-model models\vosk-model-ru-0.42
run.bat --calibrate                      rem проверьте свой голос заново
run.bat
```

```bash
# Linux:
./run.sh --download-model ru-big
./run.sh --set-model models/vosk-model-ru-0.42
./run.sh --calibrate
./run.sh
```

Загрузчик умеет **докачивать** модель после обрывов: при разрыве соединения
оставшиеся байты запрашиваются через `Range`-заголовки, скачанное не теряется.

## Передать другу / на телефон

Нужно отправить **только исходники** (`.venv` и `models/` не нужны — они
создаются у друга сами). Есть готовый скрипт упаковки:

```bash
./make_release.sh        # создаёт dist/dota-voice-caster.zip (~24 КБ)
```

Что делать с архивом:

* **Telegram / WhatsApp / почта / Google Drive** — просто отправьте
  `dota-voice-caster.zip` другу. Он распакует и запустит `run.bat`.
* **Себе на телефон (для переноса/бэкапа).** Приложение на телефоне не
  заработает (нужен ПК с Dota 2 и эмуляция клавиатуры), но файлы удобно
  хранить: отправьте архив в Telegram **себе в «Избранное»** или в облако —
  оттуда потом скачаете на любой ПК.
* **Через git (если хочется получать обновления).**
  ```bash
  # на своей машине:
  git init && git add -A && git commit -m "init"
  git bundle create dota-voice-caster.bundle --all   # один файл, его и отправьте
  # у друга:
  git clone dota-voice-caster.bundle dota-voice-caster
  ```
  Либо создайте репозиторий на GitHub и клонируйте
  (`git clone <ссылка>`), тогда модель и venv всё равно не попадут в git.

> Напоминание: скачивание модели (~44 МБ или ~1.9 ГБ) происходит **у друга**
> при первом запуске — интернет нужен на его ПК.

## Как это работает

```
микрофон → Vosk (ограниченная грамматика) → commands.json → эмуляция клавиш
```

Грамматика распознавателя ограничена словами ваших команд (+ кодовое слово),
поэтому посторонняя речь почти не вызывает ложных срабатываний.

### Почему у команд есть «слова-ключи»

Маленькая модель `vosk-model-small-ru` **не знает** часть выдуманных слов
(`тефтель`, `алакрити`, `друны`, `заморозься`, `взлетите`, `емп`). В Vosk слова
вне словаря просто выкидываются из грамматики. Поэтому каждой команде задано:

* `phrases` — что вы **произносите** (ваши фразы);
* `words`   — на что **«доезжает»** распознаватель (слова, которые есть в модели
  и звучат похоже). Vosk «притягивает» вашу фразу к ближайшему такому слову.

Проверить свой голос и подстроить `words` можно командой `--calibrate`.

## Команды Инвокера

| Заклинание        | Орбы  | Ваша фраза              | `words` (ключ)      |
|-------------------|-------|-------------------------|---------------------|
| Cold Snap         | Q Q Q | заморозься              | заморозки           |
| Ghost Walk        | Q Q W | призрачная походка      | (как есть)          |
| Ice Wall          | Q Q E | стенка                  | (как есть)          |
| Tornado           | W W Q | взлетите                | взлететь            |
| EMP               | W W W | емп                     | эм                  |
| Alacrity          | W W E | алакрити                | критика             |
| Forge Spirit      | E E Q | друны, ко мне           | дроны ко мне        |
| Chaos Meteor      | E E W | великий тефтель         | великий тефтели     |
| Sun Strike        | E E E | солнечный удар          | (как есть)          |
| Deafening Blast   | Q W E | бласт                   | (как есть)          |

Кодовое слово (без него команда не сработает): **джарвис**.

## Комбо-фразы

Команда может выполняться как **последовательность** (комбо): одной фразой
можно задать несколько спеллов подряд. Например, по умолчанию есть:

* «метеор бласт» — Meteor, затем Deafening Blast (по одному месту);
* «алакрити походка» — Alacrity, затем Ghost Walk (баффы, прицеливаться не надо).

```json
{ "name": "Tornado Meteor Blast", "phrases": ["торнадо метеор бласт"],
  "combo": ["tornado", "chaos_meteor", "deafening_blast"] }
```

`combo` — список спеллов, между ними пауза `combo_delay` (по умолчанию 0.6 с).

### Прицеливание мышью

Важно: у большинства спеллов Инвокера цель — **точка/направление**, и по
умолчанию они кастуются **под текущий курсор** (курсор не двигается сам).
Чтобы комбо реально цепляло врага, у которого цель «во врага», нужно
отслеживать цель — это экранный CV/память игры, то есть отдельная большая
тема (и близко к читерству). В рамках этого приложения есть два честных пути:

1. **Quickcast** — включите его нужным спеллам в настройках Dota 2. Тогда
   горячая клавиша кастует сразу под курсором, и комбо работает с клавиатуры.
2. **Шаги с мышью** — задайте комбо вручную через `steps`: можно двигать курсор
   относительно и кликать. Тогда одна фраза сама «отведёт» цель:

```json
{ "name": "Meteor in front", "phrases": ["метеор вперёд"],
  "words": ["метеор вперёд"],
  "steps": [
    { "keys": ["e", "e", "w", "r", "d"] },   // Meteor под текущий курсор
    { "move": [0, 160] },                    // сдвинуть курсор вниз на 160px
    { "click": 1 }                           // подтвердить/каст (если нет quickcast)
  ] }
```

Шаги (`steps`) — список объектов, выполняемых по порядку:

| Шаг                | Что делает                                  |
|--------------------|---------------------------------------------|
| `{ "keys": [...] }`| нажать клавиши (с задержкой `key_delay`)    |
| `{ "move": [dx,dy] }` | сдвинуть курсор относительно, пикселей   |
| `{ "click": 1 }`   | клик левой кнопкой (1 = один раз)           |
| `{ "sleep": 0.2 }` | пауза, сек                                  |

Между шагами автоматически вставляется `combo_delay`.

> Прицеливание «во врага» (слежение за целью) **не** поддерживается: для этого
> нужен анализ игрового экрана. Сочетание «торнадо → метеор в точку
> приземления» тоже требует предсказания и в бою делается по ситуации.

## Лог и статистика

Каждое срабатывание дописывается в файл `log_file` (по умолчанию
`voice_caster.log` рядом с конфигом):

```
2026-10-12 21:33:07  Meteor Blast  keys=EEW R D + QWE R D
```

При выходе (Ctrl+C) в консоль печатается сводка за сессию: сколько раз
сработала каждая команда и сколько фраз распознать не удалось. Отключить лог:
`"log_file": null`.

## SSK mode / Polina mode — «челлендж» перед скиллом

Дополнительные режимы-«челлендж», которые мешают автокасту в один клик: перед
**каждым нажатием скилл-клавиши** нужно доказать, что за компьютером человек.
Работает на **любом герое**, не только на Инвокере — список «скилловых» клавиш
задаётся настройкой `challenge_keys` (по умолчанию `q w e r d f` — кнопки
способностей всех героев, включая орбы/инвок/каст Инвокера).

Два режима (`challenge_mode`):

* **`ssk` (SSK mode)** — в оверлее **поверх игры** показывается случайный
  пароль из `ssk_length` символов (латиница + цифры, **без кириллицы**);
  его нужно ввести целиком. Пароль новый на каждое нажатие.
* **`polina` (Polina mode)** — показывается **один** случайный символ
  (буквы + цифры + пунктуация, т.е. основные клавиши 60%‑клавиатуры: `- = [ ] ;
  ' , . / \`` и т.п., без Shift); нужно нажать этот символ.

Как включить:

* поставить `"challenge_mode": "ssk"` или `"polina"` в `settings` конфига,
  **или**
* запустить с ключом `--ssk-mode` (SSK mode), **или**
* запустить с ключом `--polina-mode` (Polina mode).

Настройки:

* `challenge_mode` — `"off"`, `"ssk"` или `"polina"` (по умолчанию `"off"`);
* `challenge_keys` — какие клавиши считаются скиллами
  (по умолчанию `["q", "w", "e", "r", "d", "f"]`);
* `ssk_length` — длина пароля в SSK mode (по умолчанию `8`);
* `challenge_timeout` — сколько секунд ждать ввода (`null` — ждать сколько нужно).

Ключ `--challenge-keys qwer` позволяет разово задать список скилл-клавиш,
например только орбы Инвокера.

Как это работает и важные детали:

* ввод ловится **глобально** (`pynput`), поэтому игра может быть в фокусе;
* на **Windows** введённые символы **не попадают в игру** (подавляются), т.к.
  читаются физические клавиши по коду — раскладка (RU/EN) значения не имеет;
* на Linux подавление ввода системой не поддерживается: челлендж сработает, но
  набранные символы могут параллельно уйти в активное окно;
* если графический дисплей недоступен, челлендж запрашивается в консоли;
* клавиши читаются **по физическим позициям**, регистр/Shift не важны;
* пока идёт челлендж, остальные фразы не обрабатываются.

> Челлендж берётся **перед каждым** скиллом, поэтому сильно замедляет игру:
> `Cold Snap` (`Q Q Q`) в SSK mode — **три** пароля, в Polina mode — три символа.
> Возьмите узкий `challenge_keys`, если нужно мягче.
>
> Старые настройки `orb_password` / `password_mode` / `password_length` /
> `password_keys` / `password_cast_keys` / `password_timeout` из прежних версий
> автоматически переносятся в SSK mode.

## Настройка — `commands.json`

Создаётся автоматически при первом запуске.

```json
{
  "settings": {
    "model_path": "models/vosk-model-small-ru-0.22",
    "wake_word": "джарвис",
    "wake_timeout": 4.0,
    "cooldown": 0.6,
    "key_delay": 0.04,
    "combo_delay": 0.6,
    "log_file": "voice_caster.log",
    "challenge_mode": "off",
    "challenge_keys": ["q", "w", "e", "r", "d", "f"],
    "ssk_length": 8,
    "challenge_timeout": null
  },
  "commands": [
    { "name": "Chaos Meteor", "spell": "chaos_meteor",
      "phrases": ["великий тефтель"], "words": ["великий тефтели"] },
    { "name": "Мой макрос", "phrases": ["пощады"],
      "words": ["пощады"], "keys": ["q", "w", "e", "r", "d"] },
    { "name": "Комбо", "phrases": ["метеор бласт"],
      "combo": ["chaos_meteor", "deafening_blast"] }
  ]
}
```

* `spell` — готовый спелл Инвокера (см. таблицу), макрос соберётся сам;
* `keys`  — произвольная последовательность клавиш (`q w e r d`);
* `combo` — список спеллов: несколько кастов подряд, между ними `combo_delay`;
* `steps` — то же, но вручную: клавиши/движение мыши/клик/пауза (см. выше);
* `phrases` — что говорите; `words` — слова для грамматики (по умолчанию = `phrases`);
* `slot`  — кнопка каста `d` или `f`;
* `cooldown` — пауза между повторами команды, сек;
* `log_file` — файл лога (`null` — отключить);
* `wake_word` — кодовое слово (`null` — отключить);
* `challenge_mode` / `challenge_keys` / `ssk_length` / `challenge_timeout` —
  SSK/Polina mode (см. раздел выше).

## Ключи запуска

| ключ                     | назначение                                         |
|--------------------------|----------------------------------------------------|
| `--download-model ru`    | скачать модель речи (`ru`, `en`, `ru-big`, `en-big`) |
| `--set-model <путь>`     | записать путь к модели и выйти                      |
| `--calibrate`            | проверить распознавание вашим голосом              |
| `--check`                | проверить слова команд по словарю модели           |
| `--list-devices`         | список микрофонов                                  |
| `--device N`             | выбрать микрофон                                   |
| `--dry-run`              | не отправлять клавиши, только печатать             |
| `--ssk-mode`             | SSK mode: ввести пароль перед каждым скиллом       |
| `--polina-mode`          | Polina mode: нажать случайный символ перед скиллом |
| `--challenge-keys qwer`  | какие клавиши считаются скиллами                   |
| `--test-keys`            | проверить эмуляцию (отправит `q w e r d`)          |
| `--slot f`               | кастовать во второй слот (`F`)                     |
| `--init`                 | создать `commands.json`                            |
| `-v`                     | показывать промежуточные распознавания             |

## Если что-то не работает

* **Скачивание модели** идёт с зеркал (HuggingFace → alphacephei), а при
  обрыве соединения загрузка автоматически докачивается с места разрыва.
* **Слово не распознаётся** — запустите `--check` (покажет слова вне словаря) и
  `--calibrate`, затем подберите `words` поближе по звучанию.
* **На Linux/Wayland** без `ydotool` клавиши не отправляются — это ограничение
  системы, а не приложения.
* Dota должна быть **в фокусе**, иначе клавиши уйдут в другое окно.
